# 四合一电调 PWM 控制接口 Layout

## GND

- 必须与主控 GND 共地
- 接口 GND 直接接主 GND 平面
- 不要细长绕线
- 接口附近保持完整铺地
- 不要让电机大电流回流经过接口附近

## 8.0 / 8.1 / 8.2 / 8.3

- 四根线大概率是四路 PWM 控制输入
- PWM 频率范围一般为 50Hz~300Hz
- 不属于高速线，但抗干扰很重要
- 尽量短、直
- 可以并排走线
- 不需要严格等长
- 下方保持完整 GND
- 不要靠近 MOS、三相线、DC-DC、电感
- 不要和电机三相线长距离平行

## 抗干扰建议

- 可预留串联电阻：100Ω~1kΩ
- 可预留下拉电阻：10kΩ~100kΩ
- 可预留小电容：100pF~1nF
- 电容不要过大，避免影响 PWM 脉宽识别

## NC 引脚

- 保持悬空
- 不要误接 GND 或 VCC
