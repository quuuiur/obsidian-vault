# 无线模块 UART 接口 Layout 注意事项

## 1. 电源 VCC5V_EXT

无线模块对供电稳定性比较敏感，Layout 时应优先保证电源质量：

- 电源线建议使用 15~25mil
- 推荐使用 `0.1uF + 10uF` 去耦
- 去耦电容尽量靠近接口
- 电源线不要和电机供电并行
- 避免靠近 DC-DC、电机驱动、电感等强干扰区域

---

## 2. GND

GND 处理注意事项：

- 接口区域保持完整 GND
- 接口周围建议增加 GND Via
- 避免跨地缝
- 避免大电流回流经过无线模块接口区域

---

## 3. UART_TX / UART_RX

UART 属于低速通信接口，信号完整性要求不高：

- TX/RX 并行走线即可
- 不要绕大圈
- 避免贴近 PWM、电机、DC-DC 等干扰源
- 不需要严格等长
- 走线下方尽量保持完整 GND 参考平面

---

## 4. KEY / EN / STATE

KEY、EN、STATE 等控制或状态信号按普通 GPIO 处理即可：

- 不要绕线过长
- 避免贴近强干扰区域
- 远离 PWM、电机驱动、DC-DC 等噪声源

---

## 5. 天线区域

天线区域是无线模块 Layout 中最重要的部分。

### 5.1 禁止事项

无线模块天线区域禁止：

- 铺铜
- 走线
- 放置 GND
- 放置电源
- 放置元器件

### 5.2 推荐做法

天线下方和前方应预留净空区域：

```text
Keepout 空白区域
```

如果天线区域处理不当，可能导致：

- 无线距离下降
- 信号质量变差
- 通信稳定性下降

---

## 6. 模块位置

### 6.1 推荐位置

无线模块摆放建议：

- 靠近 PCB 边缘
- 天线朝外
- 天线方向尽量远离板内高噪声区域

### 6.2 避免位置

无线模块应避免靠近：

- 电机
- DC-DC
- 电感
- 大电流走线
- 大面积铜皮
- 金属结构

---

## 7. 核心原则

无线模块 Layout 真正关键的是：

- 电源稳定
- 地平面完整
- 天线净空

UART 信号本身要求反而不高。Layout 时应优先保证供电、地和天线区域。
