# IMU660RB Layout 注意事项

## 1. 推荐接口

推荐使用 **SPI** 接口：

- 速度更快
- 延迟更低
- 更适合智能车姿态解算

---

## 2. SPI 信号布线

### 2.1 SCK / SPC

SPI 时钟线属于高速信号，Layout 时优先保证 SCK 质量：

- SCK 走线尽量最短、最直
- 尽量减少过孔
- 走线下方保持完整 GND 参考平面
- 不要靠近 PWM、电机、DC-DC、电感等强干扰区域

推荐串联阻尼电阻：

```text
MCU_SCK ---22Ω~33Ω--- IMU_SCK
```

### 2.2 MOSI / SDI

MOSI 是 MCU 到 IMU 的数据线：

- 尽量靠近 SCK 走线
- 尽量减少过孔
- 不要绕远路
- 走线下方保持完整 GND 参考平面

### 2.3 MISO / SDO

MISO 是 IMU 到 MCU 的数据线：

- 尽量靠近 SCK 走线
- 不要长距离绕线
- 尽量减少过孔

### 2.4 CS

SPI 片选线按普通数字信号处理即可：

- 不需要按高速线特别处理
- 避免贴近强干扰区域

---

## 3. 中断信号

### INT1 / INT2

中断输出信号 Layout 注意事项：

- 不要绕很远
- 避免贴近 PWM 信号
- 避免经过电机驱动、大电流走线附近

---

## 4. 供电与去耦

### 4.1 VCC

IMU 对供电噪声比较敏感，建议在电源引脚附近放置去耦电容：

```text
0.1uF + 1uF
```

Layout 要点：

- 去耦电容尽量贴近 IMU 电源引脚
- 电容回流路径要短
- 供电走线避免靠近 DC-DC、电机驱动、PWM 等噪声源

### 4.2 GND

GND 处理对 IMU 稳定性非常重要：

- IMU 下方保持完整 GND
- IMU 周围建议增加 GND Via
- 避免大电流回流经过 IMU 区域
- 避免在 IMU 下方切割地平面

---

## 5. IMU 摆放位置

IMU 摆放建议：

- 尽量靠近 PCB 中心
- 远离电机
- 远离电机驱动、电源开关管、电感等大电流或强振动区域
- 尽量避开板边和容易受机械冲击的位置

---

## 6. 核心原则

IMU660RB 在实际使用中更怕：

- 电源噪声
- 地噪声
- 机械震动

相比之下，SPI 信号问题通常不是主要矛盾。Layout 时应优先保证供电、地、摆放位置和机械稳定性。
