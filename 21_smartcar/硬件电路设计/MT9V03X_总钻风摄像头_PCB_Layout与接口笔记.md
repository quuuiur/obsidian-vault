# MT9V03X（总钻风）摄像头模块 PCB Layout 与接口笔记

## 一、摄像头接口总体说明

MT9V03X 属于：

- CMOS 并口灰度摄像头
- 8 bit 并行数据输出
- 高速数字接口

核心接口包括：

| 信号 | 类型 | 作用 |
| --- | --- | --- |
| PCLK | 时钟 | 像素采样时钟 |
| D0~D7 | 数据 | 图像像素数据 |
| VSYNC | 同步 | 帧同步 |
| HREF | 同步 | 行同步 |
| TXD/RXD | UART | 摄像头参数配置 |
| 3V3 | 电源 | 3.3 V 供电 |
| GND | 地 | 系统参考地 |

## 二、核心信号作用

### 1. PCLK（Pixel Clock）

#### 作用

PCLK 是像素采样时钟。

每来一个时钟，MCU 读取一次 D0~D7 数据。

#### 工作逻辑

```text
PCLK 到来
↓
读取 D0~D7
↓
得到一个像素
```

#### 重要性

PCLK 是最高优先级信号。

PCLK 出问题会导致：

- 花屏
- 错位
- 丢帧
- 图像乱码

### 2. D0~D7（8 bit 数据总线）

#### 作用

D0~D7 输出像素灰度值。

例如：

```text
00000000 = 黑
11111111 = 白
```

每个 PCLK 对应一个像素数据。

#### 注意

数据线必须按位顺序连接：

```text
D0 -> DATA0
D1 -> DATA1
D2 -> DATA2
D3 -> DATA3
D4 -> DATA4
D5 -> DATA5
D6 -> DATA6
D7 -> DATA7
```

不能乱接。

### 3. VSYNC（Frame Sync）

#### 作用

VSYNC 是帧同步信号，用于告诉 MCU：

```text
新的一帧图像开始了
```

#### 作用理解

VSYNC 控制：

- 一张图开始
- 一张图结束

### 4. HREF（Line Sync）

#### 作用

HREF 是行同步信号，用于告诉 MCU：

```text
当前这一行有效
```

#### 工作方式

```text
HREF 高电平：
当前行为有效图像数据

HREF 低电平：
当前行为无效区域
```

### 5. TXD / RXD

#### 作用

TXD/RXD 是串口配置接口，用于：

- 设置曝光
- 修改帧率
- 配置增益
- 调整图像参数

#### 注意

TXD/RXD 不传输图像数据，仅用于配置。

### 6. 3V3

#### 作用

3V3 是摄像头供电。

#### 注意

MT9V03X 一般工作于：

```text
3.3 V
```

严禁直接接 5 V，否则可能烧毁。

### 7. GND

#### 作用

GND 是系统参考地，必须与 MCU 共地。

## 三、信号关系理解

```text
VSYNC -> 一张图开始
HREF  -> 一行开始
PCLK  -> 一个像素到来
D0~D7 -> 像素内容
```

MCU 的工作过程：

```text
等待 VSYNC
↓
等待 HREF
↓
在 PCLK 到来时读取 D0~D7
↓
拼成整张图像
```

## 四、PCB Layout 总原则

### 1. 摄像头必须靠近 MCU

建议：

```text
摄像头 ↔ MCU
距离越短越好
```

推荐：

```text
3~5 cm 以内
```

尤其是以下信号必须短：

- PCLK
- D0~D7

### 2. 摄像头远离干扰源

必须远离：

- 电机驱动
- H 桥
- DC-DC
- MOS
- PWM 大电流区域

否则可能出现：

- 雪花
- 条纹
- 花屏

### 3. 摄像头区域必须完整铺地

要求：

```text
高速线下方必须有连续 GND
```

不能出现：

- 地平面断裂
- 高速线跨地缝

否则回流路径会异常。

## 五、PCLK Layout（最高优先级）

### 1. 走线最短

PCLK 优先级最高。

要求：

- 短
- 直
- 少拐弯

### 2. 尽量不要过孔

过孔会：

- 增加寄生电感
- 引入阻抗突变

可能导致时钟质量下降。

### 3. 远离干扰源

PCLK 不要靠近：

- PWM
- 电源
- 电机线
- 晶振

### 4. 下方必须完整 GND

PCLK 下方必须始终有完整地平面。

### 5. 建议串联匹配电阻

推荐：

```text
22 Ω ~ 33 Ω
```

连接方式：

```text
PCLK ---22R--- MCU
```

作用：

- 抑制振铃
- 减少过冲
- 提高信号完整性

## 六、D0~D7 数据线 Layout

### 1. 尽量等长

因为 MCU 会同时采样 D0~D7。

长度差过大可能产生时序偏差。

### 2. 推荐长度误差

建议：

```text
误差 < 5 mm
```

### 3. 尽量并排走线

推荐：

```text
D0 D1 D2 D3 D4 D5 D6 D7
```

整齐排列。

### 4. 避免蛇形线过多

过多蛇形线会增加串扰。

### 5. 尽量同层完成

减少：

- 过孔
- 延迟差

## 七、VSYNC / HREF Layout

### 1. 与 PCLK 靠近

VSYNC/HREF 与 PCLK 属于同一时序域。

### 2. 不需要严格等长

VSYNC/HREF 不需要严格等长，但不要差距过大。

### 3. 避免绕线

绕线过长可能导致：

- 行错位
- 帧错位

## 八、TXD/RXD Layout

UART 速率较低，要求最低。

建议：

- 避免贴近电机线
- 不要特别长

## 九、电源 Layout（非常关键）

### 1. 摄像头建议单独滤波

推荐：

```text
主 3V3
  |
 磁珠
  |
摄像头 3V3
```

### 2. 去耦电容必须靠近 VCC

推荐：

```text
0.1 uF + 1 uF + 10 uF
```

其中：

```text
0.1 uF
```

必须最靠近芯片。

### 3. 电源线适当加粗

建议：

```text
10~20 mil
```

## 十、GND Layout

### 1. 大面积铺地

摄像头区域必须完整 GND。

### 2. 不要割裂地平面

禁止：

```text
高速信号跨地缝
```

### 3. 多打地过孔

推荐在以下位置增加 GND Via：

- 摄像头附近
- 排针附近

## 十一、2 层板推荐方案

### 顶层

顶层走：

- PCLK
- D0~D7
- VSYNC
- HREF

### 底层

底层尽量：

```text
整面 GND
```

不要乱切割。

## 十二、Layout 优先级

PCB 布线时推荐顺序：

| 优先级 | 内容 |
| --- | --- |
| 1 | GND 完整性 |
| 2 | PCLK |
| 3 | D0~D7 |
| 4 | VSYNC/HREF |
| 5 | 电源 |
| 6 | TXD/RXD |

## 十三、智能车常见错误

### 错误 1：摄像头离 MCU 太远

```text
摄像头离 MCU 太远
```

### 错误 2：PCLK 乱走线

```text
PCLK 乱走线
```

### 错误 3：摄像头靠近电机驱动

```text
摄像头靠近电机驱动
```

### 错误 4：没有完整 GND 平面

```text
没有完整 GND 平面
```

### 错误 5：D0~D7 长度差巨大

```text
D0~D7 长度差巨大
```

## 十四、推荐布线流程

```text
先放 MCU
↓
再放 摄像头接口
↓
先布 PCLK
↓
再布 D0~D7
↓
再布 VSYNC/HREF
↓
最后布其他信号
```

## 十五、总结

MT9V03X 属于高速并口设备。

核心原则：

```text
短
直
等长
完整地平面
远离干扰
```

其中，PCLK 是最关键的信号。
